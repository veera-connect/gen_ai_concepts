LANGCHAIN DOCUMENT SPLITTING (CHUNKING) – SIMPLE PRACTICAL NOTEBOOK

This notebook is based on the structure and teaching style of the uploaded
Langchain_Chunking.ipynb reference.

Included:
- Individual imports and separate execution cells
- Simple explanations before each topic
- CharacterTextSplitter
- RecursiveCharacterTextSplitter
- TokenTextSplitter and token counting
- MarkdownHeaderTextSplitter
- HTMLHeaderTextSplitter
- Chunk size and chunk overlap examples
- Semantic chunking
- Parent-child chunking demonstration

How to use:
1. Extract this ZIP.
2. Open the extracted folder in Jupyter Notebook or JupyterLab.
3. Open LangChain_Chunking_Simple.ipynb.
4. Run cells from top to bottom.
5. Use the sample files in Data_files or replace paths with your own files.

Note:
Semantic chunking downloads a local embedding model on first use and may require
internet access. Other basic splitter examples do not require an embedding model.
