LANGCHAIN DOCUMENT LOADERS - SIMPLE NOTEBOOK

This notebook follows the simple structure of the uploaded reference notebooks:
- individual import statements
- one small code execution per step
- simple file paths
- separate load(), len(), page_content, and metadata cells
- short explanations before each code section

How to use:
1. Extract the ZIP file.
2. Open the extracted folder in Jupyter Notebook.
3. Open LangChain_Document_Loaders_Simple.ipynb.
4. Run cells one by one from top to bottom.
5. Replace sample file paths with your own local document paths when practising.

Sample documents are provided in Data_files.
The WebBaseLoader example requires internet access.
